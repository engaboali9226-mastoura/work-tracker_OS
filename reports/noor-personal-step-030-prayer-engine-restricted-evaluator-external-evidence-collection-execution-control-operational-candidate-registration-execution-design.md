## Execution Outcomes

- EXECUTION_REJECTED — request or authority failed before evaluation.
- QUARANTINED — blocking validation, safety, capability, dependency, evidence, or conflict findings remain.
- REVIEW_READY_PROJECTED — all mandatory gates pass in a non-persistent dry run.
- APPROVAL_PROJECTED — independent review would approve the exact sealed revision.
- REJECTION_PROJECTED — independent review would reject the exact sealed revision.
- REVALIDATION_REQUIRED — prior projection expired or a material input changed.
